# 功能概览

## 知识库
- 独立、可复用的本地知识库
- PDF、DOCX、Markdown、TXT 导入
- 标签、筛选、回收站与批量任务
- Markdown 笔记、双链、反链与图谱

## 阅读与检索
- PDF / DOCX 原版分页与结构化阅读
- 关键词、语义与混合检索
- 命中片段、来源分数和原文预览
- 页码或段落级引用锚点

## 智能体
- 云端模型 API 优先
- 多轮知识库检索和来源核查
- 研究任务进度、工具调用与来源可见
- 生成笔记或报告前预览确认

## MCP
- 安全令牌与连接状态
- 只读访问和写入策略分离
- 可选用户明确授权的自动写入

以官网 [功能页](https://velaryn.cn/features/) 为最新产品事实来源。
