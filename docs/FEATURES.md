# 功能概览

## 知识库
- 独立、可复用的本地知识库
- PDF、DOCX、Markdown、TXT 导入
- 标签、筛选、回收站与批量任务
- Markdown 笔记、双链、反链与图谱

## 阅读与检索
- PDF / DOCX 原版分页与结构化阅读
- 关键词、语义与混合检索
- 命中片段、来源分数和原文预览
- 页码或段落级引用锚点
- 摘录、解释、翻译、提问、笔记、建链和制卡
- 阅读位置恢复、阅读进度和最近阅读
- 检索实验室、固定问题回归集与配置 A/B
- 查询改写、多查询、父子上下文和可选模型重排

## 采集与网页剪藏
- Android 系统分享与持久化知识收集箱
- 网页正文提取、噪声清洗和无脚本 HTML 快照
- 抓取预览、失败重试、仅保存链接和规范化 URL 去重
- 批量入库、批量忽略与来源元数据保留

## 智能体
- 云端模型 API 优先
- 多轮知识库检索和来源核查
- 研究任务进度、工具调用与来源可见
- 生成笔记或报告前预览确认

## MCP
- 安全令牌与连接状态
- 只读访问和写入策略分离
- 可选用户明确授权的自动写入
- 单篇/批量逐行 Diff、乐观并发保护与历史恢复
- 幂等键、审批状态和操作审计

以官网 [功能页](https://velaryn.cn/features/) 为最新产品事实来源。
