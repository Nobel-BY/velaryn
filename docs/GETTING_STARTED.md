# 快速开始

## 1. 安装
从 https://velaryn.cn/download/ 下载 APK，确认 Android 12+、ARM64，并核对 SHA-256。

## 2. 建立第一个知识库
创建知识库后先导入少量高质量 PDF、DOCX、Markdown 或 TXT。Beta 阶段请保留原文件备份。

## 3. 配置模型 API
Velaryn 以用户配置的云端模型 API 为主。知识检索在设备本地完成，只把当前任务需要的上下文发送给模型服务。

## 4. 验证引用
先提出一个能在原文中找到明确答案的问题，确认引用可以打开正确资料与位置。

在检索实验室中把这个问题保存为回归用例；调整查询改写、重排或候选数量前，先运行已保存配置与草稿配置 A/B，确认没有来源召回退步。

## 5. 尝试研究任务
选择多个资料，让智能体比较观点、指出冲突并生成带引用报告。写回知识库前检查预览内容。

通过 Agent 或 MCP 修改已有 Markdown 笔记时，应核对逐行 Diff。若提示版本冲突，请重新打开最新版本后再合并，不要重试覆盖旧版本。

完整文档：https://velaryn.cn/docs/
